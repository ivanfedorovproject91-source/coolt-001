# Как сделать, чтобы обложка приходила в Telegram (бесплатно)

Схема: приложение → Cloudflare Worker (бесплатный посредник) → ваш бот присылает файл вам в чат.

## 1. Бот
1. В Telegram откройте @BotFather → /newbot → придумайте имя и логин.
2. Скопируйте токен (строка вида 123456:ABC...). Никому его не показывайте и не вставляйте в код.

## 2. Cloudflare Worker
1. Зарегистрируйтесь на https://dash.cloudflare.com (карта не нужна).
2. Workers & Pages → Create → Create Worker → дайте имя (например coolt-bot) → Deploy.
3. Нажмите Edit code, удалите всё, вставьте содержимое файла bot/worker.js → Deploy.
4. Settings → Variables and Secrets → Add:
   - BOT_TOKEN, тип Secret, значение: токен бота.
   - ALLOWED_ORIGIN, тип Text, значение: https://ВАШ_ЛОГИН.github.io (только адрес, без / и без названия репозитория).
5. Deploy ещё раз. Скопируйте адрес воркера: https://coolt-bot.ВАШ_АККАУНТ.workers.dev

## 3. Приложение
1. В index.html найдите строку const WORKER_URL='';
2. Вставьте адрес: const WORKER_URL='https://coolt-bot.ВАШ_АККАУНТ.workers.dev';
3. Загрузите index.html на GitHub (замените старый), подождите 1-2 минуты.

## 4. Запуск
1. @BotFather → /mybots → ваш бот → Bot Settings → Menu Button → Configure → ссылка на приложение (https://ВАШ_ЛОГИН.github.io/РЕПОЗИТОРИЙ/).
2. Откройте чат с ботом и нажмите /start (обязательно: бот может писать только тем, кто его запускал).
3. Откройте приложение кнопкой меню бота, соберите обложку, Экспорт → «Отправить мне в Telegram».

Кнопка появляется только внутри Telegram и только если указан WORKER_URL.

## Если ошибка
- «chat not found» / «blocked»: нажмите /start в чате с ботом.
- «Не удалось подтвердить пользователя»: открыто не через бота, или неверный BOT_TOKEN.
- Ошибка сети: проверьте WORKER_URL и ALLOWED_ORIGIN (без лишнего / на конце).
- Файл большой и воркер падает: выберите 2000 px или формат JPG.
Бесплатный лимит Cloudflare: 100 000 запросов в сутки, для лейбла более чем достаточно.
