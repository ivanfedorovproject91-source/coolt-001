# COOLT EDITOR
Telegram Mini App. Файлы: index.html + папка assets (logo.png, coolt.png, gotthard.otf).
1. Загрузите всё в репозиторий GitHub (index.html в корне).
2. Settings → Pages → Branch: main / root.
3. Ссылку https://<логин>.github.io/<репозиторий>/ укажите в @BotFather: /newapp или Menu Button.
